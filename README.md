# AlgoPipX Educational Assistant

A Telegram educational assistant built with Python, python-telegram-bot, and aiohttp.

The bot provides educational resources, FAQs, language selection, user management, and admin tools.

---

## Features

✅ Telegram Bot  
✅ Webhook Support  
✅ Render Deployment Ready  
✅ SQLite Database  
✅ FAQ System  
✅ Admin FAQ Management  
✅ User Statistics  
✅ Broadcast Messages  
✅ Language Selection  
✅ Support Contact Button  
✅ Channel Button
